# おてつだいブラザーズ

男の子の兄弟2人向けの「おてつだい × おこづかい」PWAアプリ。
**比べすぎない・取り合いにしない・協力でボーナスが出る**が基本方針。

## 特徴

- 兄弟それぞれのポイント通帳・スタンプ帳（個人ランキングは出さない）
- 兄弟ミッション：2人そろって達成で協力スタンプ、週3回でボーナス50ptずつ
- 担当チェンジ制：トイレ掃除と机ふきは月水金/火木土で交代、日曜は協力デー
- 子どもの「できた！」→ 親の承認（かけ算ゲート）→ ポイント確定の2段階
- ごほうびショップ・ほしいものリスト・ありがとうカード
- 兄弟合計300ptごとに家族イベントチケット
- 週の獲得上限（デフォルト300pt/人）超過時は親画面に警告

## 技術

- 素のHTML/CSS/JS + PWA（オフライン動作・通信/課金/広告なし）
- データは端末内 localStorage のみ。バックアップは親画面からJSONで保存/復元
- **1台の端末（家族共用タブレット/親のスマホ）での運用を想定**。端末間の自動同期はなし

## ローカル確認

preview launch設定 `otetsudai`（port 8644）、または:

```
python -m http.server 8644 --directory otetsudai-brothers
```
